# Development Rules

## MVP

Build the smallest working solution first.

## AI

Use Gemini when it can solve the task faster or better than custom implementation.

## Code

Keep modules small and focused.

## Testing

Test with real videos as early as possible.

## Architecture

Do not add complexity before it is required.

## Current Priority

The immediate priority is:

Video > Processing > Gemini > Structured Result > Output

Everything else is secondary until this pipeline works.
