# 🎵 Библиотека Фоновой Музыки (Audio Library)

Эта папка является постоянным хранилищем музыкальных треков, звуковых эффектов (SFX) и фонового аудио для использования при монтаже роликов.

## 📁 Назначение папки
Здесь находятся оригинальные или лицензированные MP3/WAV файлы, которые модуль сборки (`src/composer/assembler.py`) накладывает на видеоряд в качестве фоновой музыки.

## 📄 Требования к файлам
* **Формат:** `.mp3` или `.wav`
* **Качество:** от 192 kbps (рекомендуется 320 kbps)
* **Именование:** понятные латинские названия без пробелов (например, `upbeat_dance.mp3`, `calm_ambient.mp3`, `energy_beat_01.mp3`).

## ⚙️ Использование в проекте
Пути к файлам из этой папки указываются в монтажном плане (`montage_plan.json`) в блоке:
```json
"audio": {
  "background_music": "04_LIBRARY/audio/upbeat_dance.mp3"
}
